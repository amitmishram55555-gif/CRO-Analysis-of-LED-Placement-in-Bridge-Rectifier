# CRO-Analysis-of-LED-Placement-in-Bridge-Rectifier
This project analyzes how different LED placements in a full-wave bridge rectifier affect the CRO waveform. I also altered the circuit configuration to observe how small changes in component placement lead to different waveform characteristics and circuit behavior.
The problems I firstly faced was the voltage drops recoded on CRO was so random when I played with circuit then later on I researched about the Notched Humps and Truncated Humps.
Anyone interested  in the circuit or CRO images can refer the Project File.
